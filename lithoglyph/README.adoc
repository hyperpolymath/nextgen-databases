= Lithoglyph — extracted
:icons: font

Lithoglyph no longer lives here. It is developed at:

https://github.com/hyperpolymath/lithoglyph[hyperpolymath/lithoglyph]

The 819 files that used to sit under this directory were removed on 2026-07-27,
after the extraction they were waiting on completed
(`hyperpolymath/lithoglyph#4`, merged). Keeping them here left the whole database
in two places with no canonical copy — the defect the extraction existed to fix.

== Where each part went

[cols="2,3"]
|===
| Was | Now

| `lithoglyph/` (the core)
| https://github.com/hyperpolymath/lithoglyph[hyperpolymath/lithoglyph]

| `lithoglyph/glyphbase/` (130 files)
| https://github.com/hyperpolymath/glyphbase[hyperpolymath/glyphbase]

| `lithoglyph/gql-dt/` (125 files)
| https://github.com/hyperpolymath/gnpl[hyperpolymath/gnpl]

| `lithoglyph/core-factor/gql/`, `gql-c-api/`
| Superseded, not migrated — see below
|===

`core-factor/gql/` was the runtime counterpart to GQLdt's compile-time proofs. A
typed narration layer lowering to GQLdt replaces it, so it was never migrated and
should not be "finished". See `docs/migration/RESITE-DATABASES-TO-OWN-REPOS.adoc`
and the GNPL re-scope recorded in #56.

== Nothing was lost

Every file removed here is preserved at its original path in the annotated tag
`split-history/lithoglyph`, which is on `origin` and holds all 819 files across
68 commits of granular pre-squash history:

[source,console]
----
$ git ls-tree -r split-history/lithoglyph --name-only | wc -l
819
----

To recover any file:

[source,console]
----
git checkout split-history/lithoglyph -- <path>
----

**Never prune** `split-history/lithoglyph` or the `_split_lithoglyph` branch, nor
their `glyphbase` and `gnpl` equivalents. The imports into the standalone repos
were squash merges, so these refs are the only granular history that exists.
