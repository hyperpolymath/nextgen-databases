= VeriSimDB — extracted
:icons: font

VeriSimDB no longer lives here. It is developed at:

https://github.com/hyperpolymath/verisimdb[hyperpolymath/verisimdb]

The 713 files that used to sit under this directory were removed on 2026-08-03,
after the work that existed *only* here was recovered upstream
(`hyperpolymath/verisimdb#219`, merged).

== This was a fork, not a duplicate — and that mattered

`lithoglyph/` was removed by verifying every file was byte-identical to its own
repo first. **That check failed here.** Measured before anything was touched:

[cols="3,1"]
|===
| | Files

| Only in this directory | **108**
| Only in `hyperpolymath/verisimdb` | 175
| Common | 608
| — of those, differing in content | **333** (331 substantive)
|===

Deleting on the lithoglyph precedent would have destroyed roughly 4,000 lines of
work, including an entire tier of test coverage. The transferable lesson is the
*check*, not the deletion.

== What was recovered before this removal

Seven files had no counterpart upstream of any kind — not moved, not renamed,
not converted — and none was a stub. All are now on `verisimdb` `main`:

[cols="3,1,4"]
|===
| File | Lines | What

| `test/verisim/aspect/concurrency_test.exs` | 444 | Concurrency suite
| `test/verisim/aspect/security_test.exs` | 436 | Security suite
| `test/verisim/e2e_verisimdb_test.exs` | 410 | End-to-end suite
| `test/verisim/consensus/kraft_property_test.exs` | 328 | Kraft consensus property suite
| `rust-core/verisim-api/src/groove.rs` | 890 | Groove Protocol lifecycle + `/.well-known/groove`
| `rust-core/verisim-api/src/a2ml.rs` | 360 | A2ML response helpers (the no-JSON-emit rule)
| `rust-core/verisim-octad/src/ram_promotion.rs` | 472 | Octad RAM promotion
|===

Plus `WHITEPAPER.pdf`. The four test suites run against upstream unmodified —
*5 properties, 43 tests, 0 failures* — and the Rust modules are wired into their
crates' `lib.rs` and compile (`cargo check` exit 0).

`storage_regenerator.rs` (682 lines) was deliberately **not** ported: upstream
already has `verisim-normalizer/src/regeneration.rs` and
`verisim-api/src/regenerator.rs`. It was superseded, not lost.

The remaining 100 files were triaged as moved (16), converted (26), or
superseded prose, config and retired ReScript. Full working:
`docs/migration/` and the estate notes named below.

== Nothing is lost

Every file removed here is preserved at its original path in the annotated tag
`split-history/verisimdb`, which is on `origin` and holds all 713 files across
124 commits:

[source,console]
----
$ git ls-tree -r split-history/verisimdb --name-only | wc -l
713
$ git checkout split-history/verisimdb -- <path>
----

**Never prune** `split-history/verisimdb` or the `_split_verisimdb` branch, nor
their `lithoglyph`, `glyphbase` and `gnpl` equivalents. The imports into the
standalone repos were squash merges, so these refs are the only granular history
that exists.
