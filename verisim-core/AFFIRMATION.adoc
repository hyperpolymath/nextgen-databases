== What this is

`verisim-core/` is the VerisimCore categorical-abstraction layer of the KRL stack,
incubated in this coordination repo before extraction to its own repo
`hyperpolymath/VerisimCore.jl` (see `REGISTRY.adoc`).

Stack placement (maintainer-confirmed 2026-06-19):

[literal]
krl (surface DSL) → tangle (TangleIR + type-safe core) → VerisimCore (categorical abstraction — THIS LAYER) → Skein.jl / quandledb (storage + equivalence)

It provides:

* *Core = {Semantic, Temporal, Provenance}* — 3-shape minimum substrate
* *Federation contract* — 5 clauses for optional peers (Vector, Document, etc.)
* *VCL subset* — PROOF integrity/consistency/freshness
* *Crypto* — Ed25519 via libsodium (real crypto, no placeholders)

== Known-incomplete but honestly fenced

* *In-memory only* — No persistence layer (ephemeral Dict-backed store)
* *No concurrency control* — Single-threaded, no locking
* *Formal non-interference* — Runtime-only at arbitrary N; formal proof for arbitrary N is open (see `PROOF-NEEDS.adoc` in sibling experiment)
* *Zig FFI* — Not yet ported per hyperpolymath standard (see Status in README)
* *Network transport* — mTLS / federation peer transport not implemented
* *Julia toolchain absent this session* — `Pkg.test()` not run; structure and SPDX checks only. In-environment `julia --project=. -e 'using Pkg; Pkg.test()'` is authoritative
