This document tracks soundness-relevant escape hatches, trusted-base additions,
and proof obligations for the nextgen-databases coordination repository.
Per estate policy, any use of `// TRUSTED:`, `// AXIOM:`, `believe_me`,
`unsafeCoerce`, `Obj.magic`, or equivalent must be documented here with
justification, scope, and expiry/review date.

== Current Status (2026-09-25)

*Coordination repo — no proof-bearing implementation code.*

As of 2026-09-25, `nextgen-databases` is a **coordination repository** (see
`0-AI-MANIFEST.a2ml`, `REGISTRY.adoc`). Per-database implementation — including
all proof-bearing files (Idris2, Lean, TLA+) — has been extracted to owning
repositories:

- `verisimdb/` → https://github.com/hyperpolymath/verisimdb (713 files, 2026-08-03)
- `lithoglyph/` → https://github.com/hyperpolymath/lithoglyph (819 files, 2026-07-27)
- `lithoglyph/glyphbase/` → https://github.com/hyperpolymath/glyphbase
- `lithoglyph/gql-dt/` → https://github.com/hyperpolymath/gnpl (GNPL)
- `quandledb/`, `nqc/`, `typeql-experimental/`, `verisim-core/`, `verisim-modular-experiment/` → grandfathered legacy, being extracted per `REGISTRY.adoc`

Therefore, **this coordination repo itself carries no trusted-base debt**.

== Policy for New Debt

1. *Budget with comment*: `// TRUSTED: <reason> — review by <date> — issue #<n>`
2. *Axiom with justification*: `// AXIOM: <statement> — <why necessary> — <alternative considered>`
3. *Document here*: Add row to inventory above with file, type, justification, expiry
4. *CI gate*: `governance.yml` runs trusted-base reduction check; Mustfile checks `no-believe-me` and `no-unsafe-coerce` fail CI if new undocumented escape appears
5. *Owning repo*: If debt belongs to a database, document in that database's own `docs/proof-debt.md` (see `REGISTRY.adoc`), not here
